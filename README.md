# Mega RSI MTF Divergence Scanner [SHK]

<div dir="rtl">

اندیکاتور پاین‌اسکریپت (نسخه ۶) برای TradingView که روی **همان نمادی که باز کرده‌اید**، ۱۹ تایم‌فریم را هم‌زمان بررسی می‌کند، واگرایی بین قیمت و **Mega RSI** (و/یا RSI) را در هر تایم‌فریم پیدا می‌کند و وقتی **۳ تایم‌فریم پشت‌سرهم** واگرایی هم‌جهت داشته باشند، روی نمودار سیگنال می‌دهد (مثلاً `1D · 2D · 3D`).

فایل اسکریپت: [`MegaRSI_MTF_Divergence_Scanner.pine`](MegaRSI_MTF_Divergence_Scanner.pine)

## نصب

1. در TradingView پایین صفحه **Pine Editor** را باز کنید.
2. کل محتوای فایل `.pine` را کپی و جایگزین کنید، ذخیره کنید و **Add to chart** را بزنید.
3. اندیکاتور روی خود نمودار قیمت (نه پنجره‌ی جدا) قرار می‌گیرد؛ اندیکاتور Mega RSI خودتان را هم می‌توانید کنارش داشته باشید.

## نردبان تایم‌فریم‌ها

فقط همین‌ها و به همین ترتیب بررسی می‌شوند:

`5m → 10m → 15m → 30m → 1H → 2H → 3H → 4H → 6H → 8H → 10H → 12H → 1D → 2D → 3D → 1W → 2W → 3W → 1M`

«پشت‌سرهم» یعنی همسایه در همین نردبان (مثلاً `4H · 6H · 8H` یا `1W · 2W · 3W`). اگر تیک یک تایم‌فریم را در تنظیمات بردارید، از نردبان حذف می‌شود و دو همسایه‌اش پشت‌سرهم حساب می‌شوند.

## قوانین واگرایی (برای هر تایم‌فریم جداگانه)

| قانون | توضیح |
|---|---|
| اندیکاتور | همان فرمول Mega RSI شما: `CI = mom(RSI(14), 9) + SMA(RSI(3), 3)` (خط قرمز Composite Index) و RSI(14) |
| نوع مقایسه | پیش‌فرض: قیمت با **Mega RSI**. گزینه‌های دیگر: «RSI + Mega RSI (هر دو)»، «RSI یا Mega RSI»، «فقط RSI» |
| نقاط سقف/کف | پیوت قیمت با ۵ کندل چپ و ۲ کندل راست (قابل تغییر) |
| فاصله | بین دو نقطه **حداقل ۵ و حداکثر ۴۰ کندل** همان تایم‌فریم |
| صعودی (معمولی) | قیمت کف پایین‌تر، اندیکاتور کف بالاتر |
| نزولی (معمولی) | قیمت سقف بالاتر، اندیکاتور سقف پایین‌تر |
| مخفی (اختیاری، پیش‌فرض خاموش) | قیمت کف بالاتر/سقف پایین‌تر و اندیکاتور برعکس |
| خط واگرایی | هیچ کندلی بین دو نقطه نباید از خطِ وصل‌کننده‌ی آن دو رد شود (یعنی دو نقطه واقعاً کف/سقفِ بیرونی باشند) |
| اعتبار | واگرایی تا ۲۰ کندل (از همان تایم‌فریم) فعال می‌ماند، مگر قیمت پشت نقطه‌ی دوم بسته شود یا بدون واگرایی کف/سقف جدیدی فراتر از آن بسازد |

## شرط سیگنال

* ۳ تایم‌فریم پشت‌سرهمِ نردبان هم‌زمان واگرایی فعال **هم‌جهت** داشته باشند.
* (پیش‌فرض روشن) **همان سوئینگ**: نقطه‌ی دومِ واگرایی در هر سه تایم‌فریم باید داخل کندلِ سوئینگِ بزرگ‌ترین تایم‌فریمِ گروه باشد (± ۱ کندل). این جلوی ترکیب شدن واگرایی‌های بی‌ربط را می‌گیرد.
* برای هر گروه و هر سوئینگ فقط **یک بار** سیگنال داده می‌شود.
* پیش‌فرض، روی نمودار فقط گروه‌هایی علامت می‌خورند که همه‌ی تایم‌فریم‌هایشان **بزرگ‌تر یا مساوی تایم‌فریم نمودار** باشند (مثلاً روی چارت ۴ ساعته، `5m · 10m · 15m` برچسب نمی‌خورد چون صدها بار در سال رخ می‌دهد و روی کندل ۴ ساعته قابل نمایش نیست). با گزینه‌ی `All groups` همه نمایش داده می‌شوند. **جدول داشبورد همیشه همه‌ی ۱۹ تایم‌فریم را نشان می‌دهد.**

## روی نمودار چه می‌بینید

* **برچسب سیگنال** سبز `▲ BULLISH DIV` / قرمز `▼ BEARISH DIV` به‌همراه نام گروه (مثلاً `1D · 2D · 3D`). با نگه‌داشتن ماوس روی برچسب، جزئیات هر تایم‌فریم نمایش داده می‌شود (اندیکاتور، قیمت دو نقطه، چند کندل پیش).
* **خط واگرایی** روی قیمت برای هر تایم‌فریمِ گروه، با نام تایم‌فریم کنار نقطه‌ی دوم (خط‌چین = واگرایی مخفی).
* **داشبورد**: برای هر تایم‌فریم، واگرایی صعودی/نزولیِ فعال و اینکه چند کندل از آن گذشته.
  `★` = RSI و Mega RSI هر دو واگرایی دارند، `H` = مخفی، `◂` = تایم‌فریم فعلی نمودار، ردیف رنگی = عضو یک گروه فعال. ردیف `Now` گروه‌های فعالِ همین لحظه را نشان می‌دهد.

## هشدار (ربات سیگنال)

روی نمودار: **Alert → Condition:** این اندیکاتور → **Any alert() function call**.
پیام هشدار شامل جهت، نماد، تایم‌فریم‌های گروه و قیمت است، مثلاً:

```
BULLISH Mega RSI divergence | BINANCE:BTCUSDT | timeframes: 1D · 2D · 3D | price 35911.03
```

می‌توانید اعلان اپلیکیشن، ایمیل یا Webhook (مثلاً برای فرستادن به تلگرام) را فعال کنید. دو شرط ساده‌ی `Bullish MTF divergence` و `Bearish MTF divergence` هم برای هشدار جداگانه وجود دارد.

## ریپینت نمی‌کند

هر تایم‌فریم فقط با **کندل‌های بسته‌شده** محاسبه می‌شود؛ تایم‌فریم‌های بالاتر با الگوی استاندارد `expr[1] + lookahead_on` و پایین‌تر با آخرین کندل بسته‌شده‌ی داخل کندل نمودار. سیگنال هم (پیش‌فرض) بعد از بسته شدن کندل نمودار صادر می‌شود.

## محدودیت‌ها

* ۱۹ درخواست `request.security` (سقف TradingView برای پلن‌های عادی ۴۰ است).
* تاریخچه‌ی تایم‌فریم‌های **پایین‌تر** از نمودار محدود است (مثلاً ۵ دقیقه روی چارت روزانه فقط چند هفته/ماه آخر). برای دیدن سیگنال‌های قدیمیِ گروه‌های کوچک، تایم‌فریم نمودار را کوچک کنید.
* روی تایم‌فریم‌های خیلی بالا (1W تا 1M) واگرایی با این قوانین کم پیش می‌آید، چون کندل کمی وجود دارد.
* اگر TradingView برای یک تایم‌فریم سفارشی (مثل 10H یا 3W) روی حساب شما خطا داد، تیک آن را بردارید.
