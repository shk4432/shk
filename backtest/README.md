# بک‌تست Mega RSI MTF

<div dir="rtl">

تست سیگنال‌های اندیکاتور روی داده‌ی واقعی بایننس. منطق سیگنال (`engine.py`) همان منطق اسکریپت پاین است و کندل به کندل با آن مقایسه شده است.

## قوانین معامله

* **ورود:** دو حالت:
  * `signal_5m`: بسته شدن اولین کندل ۵ دقیقه‌ای که سیگنال در آن ظاهر می‌شود.
  * `smallest_tf_close`: بسته شدن کندل کوچک‌ترین تایم‌فریم گروه.
* **حد ضرر:** لانگ = لوی کندل پیووتِ نقطه‌ی دوم واگرایی، شورت = های آن. پیووتِ بزرگ‌ترین و کوچک‌ترین تایم‌فریم گروه در همه‌ی سیگنال‌ها یک قیمت بود.
* **تارگت:** 1R، 2R و 3R جداگانه.
* **حداکثر مدت:** ۲۰ کندل از بزرگ‌ترین تایم‌فریم گروه.
* **اجرای معامله:** با کندل ۵ دقیقه‌ای. اگر حد ضرر و تارگت در یک کندل لمس شوند، باخت حساب می‌شود.
* **کارمزد:** ۰٫۱٪ رفت‌وبرگشت.

## اجرا

```bash
python3 fetch.py BTCUSDT      # دانلود داده از data.binance.vision در پوشه‌ی data/
python3 backtest.py BTCUSDT   # ساخت سیگنال‌ها و شبیه‌سازی معاملات
python3 stats.py              # آمار همه‌ی نمادها
```

نمادها و بازارشان (اسپات یا فیوچرز) در `fetch.py` و بازه‌ی زمانی در `backtest.py` تعریف شده‌اند.

## نتیجه

* **گزارش کامل:** آمار هر نماد و هر گروه تایم‌فریم در گزارش آنلاین است.
* **فایل معاملات:** [`results/trades.csv`](results/trades.csv) همه‌ی ۱۴٬۴۶۶ معامله‌ی یک سال اخیر را دارد (هر دو حالت ورود). ستون‌های `result_*` مقدار `win`، `loss`، `exp` (منقضی) یا `open` (تا پایان داده باز) دارند.
