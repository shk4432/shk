# بک‌تست Mega RSI MTF

<div dir="rtl">

تست سیگنال‌های اندیکاتور روی داده‌ی واقعی. منطق سیگنال (`engine.py`) همان منطق اسکریپت پاین است و کندل به کندل با آن مقایسه شده است؛ فیلتر روند هم دقیقاً مثل اندیکاتور اعمال می‌شود.

## نمادها و داده

| بازار | نمادها | منبع | سشن |
|---|---|---|---|
| کریپتو | BTC، ETH، SOL، ZEC (اسپات)، HYPE (قرارداد دائمی) | data.binance.vision، کندل ۵ دقیقه و روزانه | ۲۴ ساعته، روز از ۰۰:۰۰ UTC |
| فارکس و طلا | EURUSD، GBPUSD، XAUUSD | histdata.com، کندل ۱ دقیقه (bid) | روز از ۱۷:۰۰ نیویورک |
| شاخص | SPXUSD (S&P 500)، NSXUSD (نزدک ۱۰۰، همان شاخص QQQ) | histdata.com، کندل ۱ دقیقه | فقط ساعات رسمی ۹:۳۰ تا ۱۶ نیویورک |

## قوانین معامله

* **ورود:** دو حالت:
  * `signal_5m`: بسته شدن اولین کندل ۵ دقیقه‌ای که سیگنال در آن ظاهر می‌شود.
  * `smallest_tf_close`: بسته شدن کندل کوچک‌ترین تایم‌فریم گروه.
* **حد ضرر:** لانگ = لوی کندل پیووتِ نقطه‌ی دوم واگرایی، شورت = های آن. پیووتِ بزرگ‌ترین و کوچک‌ترین تایم‌فریم گروه در همه‌ی سیگنال‌ها یک قیمت بود.
* **تارگت:** 1R، 2R و 3R جداگانه.
* **حداکثر مدت:** ۲۰ کندل از بزرگ‌ترین تایم‌فریم گروه (کندل واقعی، با در نظر گرفتن تعطیلی بازار).
* **اجرا:** با کندل ۵ دقیقه‌ای. اگر حد ضرر و تارگت در یک کندل لمس شوند، باخت حساب می‌شود. اگر قیمت با گپ از حد ضرر رد شود، با قیمت باز شدن کندل بسته می‌شود.
* **فیلتر روند (اختیاری):** لانگ فقط بالای EMA 200، شورت فقط زیر آن. سه حالت: EMA کوچک‌ترین تایم‌فریم گروه، بزرگ‌ترین تایم‌فریم گروه، روزانه.
* **هزینه‌ی رفت‌وبرگشت:** کریپتو ۰٫۱٪؛ فارکس، طلا و شاخص ۰٫۰۲٪.

## اجرا

```bash
python3 fetch_binance.py BTCUSDT     # کریپتو، در پوشه‌ی data/
python3 fetch_histdata.py EURUSD     # فارکس/طلا/شاخص از histdata.com
python3 backtest.py BTCUSDT          # سیگنال‌ها و معاملات → data/trades_BTCUSDT.pkl
python3 stats.py                     # آمار همه‌ی نمادها (همه‌ی فایل‌های data/trades_*.pkl لازم است)
```

## تست سیگنال هر تایم‌فریم (نسخه‌ی فعلی اندیکاتور)

`backtest_timeframes.py` منطق فعلی را تست می‌کند: هر واگرایی جدید در هر تایم‌فریم یک معامله است.
* **نمادها:** BTC، EURUSD و طلا.
* **حد ضرر:** پیووت همان تایم‌فریم.
* **بدون محدودیت زمانی:** معامله فقط با تارگت یا حد ضرر بسته می‌شود.
* **فیلتر:** با و بدون EMA 200 همان تایم‌فریم.

```bash
python3 backtest_timeframes.py BTCUSDT   # → data/trades_tf_BTCUSDT.pkl
python3 stats_timeframes.py              # آمار هر تایم‌فریم (BTCUSDT، EURUSD، XAUUSD)
```

همه‌ی ۲۲٬۰۶۲ معامله در [`results/trades_per_timeframe.csv`](results/trades_per_timeframe.csv) است، همراه با زمان خروج هر تارگت.

## نتیجه

* **گزارش کامل:** آمار هر نماد، هر گروه تایم‌فریم و هر حالت فیلتر در گزارش آنلاین است.
* **فایل معاملات:** [`results/trades.csv`](results/trades.csv) همه‌ی ۲۱٬۶۹۰ معامله‌ی یک سال اخیر را دارد (هر دو حالت ورود).
  * ستون‌های `trend_ok_*` می‌گویند معامله از هر حالت فیلتر عبور کرده یا نه.
  * ستون‌های `result_*` مقدار `win`، `loss`، `exp` (منقضی) یا `open` (تا پایان داده باز) را همراه با نتیجه بر حسب R دارند.
